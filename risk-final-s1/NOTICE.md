# Notice

## Research Release

This repository contains a research implementation of the Final-S1
Risk Assessment system developed in connection with the IEEE Big Data
Cup 2026 Explainable Suicide Risk Detection task.

## Competition Data

Competition data is not included.

Do not commit or redistribute competition post text, train data,
leaderboard data, test data, submission files, or derived files that
contain protected source text unless the relevant permissions
explicitly allow such distribution.

## Model Weights

The Git repository does not contain the 20 Final-S1 model weight
files.

The expected weight identities are documented in:

    metadata/weights_manifest.tsv

Distribution of the trained model weights should occur only after all
applicable project, team, competition, upstream-model, and
institutional permissions have been reviewed.

## Third-Party Components

Final-S1 is based on Microsoft DeBERTa-v3-large and software from the
PyTorch, Hugging Face Transformers, Safetensors, NumPy, pandas,
scikit-learn, and PyYAML ecosystems.

Third-party components remain subject to their respective licenses and
terms.
